# 자가용 출장비 자동 계산기 + 출장 증빙 보고서(PDF, 경로 지도) — v4

주소만 입력하면 **카카오내비 길찾기 API**가 경로 후보(거리·시간·통행료)를 조회하고,
**오피넷 실시간 유가**를 반영해 **사내 여비 규정(시간단위 포함)** 대로 운임·식비·일비를 산출한 뒤,
**실제 주행 경로 지도가 포함된 출장 증빙 보고서 PDF**·CSV·정산 텍스트를 생성합니다.

> 근거: **여비업무 처리 매뉴얼(2025.09.23.)** — 3.운임 나) 자가용 · 2.여비지급기준 · 4.식비 · 5.일비

## 2. 사용 순서

1. **출장 정보** — 출장자·소속·사번·목적, 시작일·종료일, **출장 구분**(근무지내/근무지외), **출장시간(시·분)**
2. **출장 경로** — 출발지·도착지 주소, 경유지(줄바꿈 구분, 최대 5개), 경로 탐색 기준 선택
   → **📍 경로·거리 자동 계산** → **경로 후보 비교표**가 표시됨
3. **경로 후보 선택** — 거리·소요시간·통행료를 비교해 라디오 버튼으로 적용 경로 선택
   (선택 시 거리·통행료·**출장시간이 자동 반영**되고 지도 갱신)
4. **차종·유종·유가** — 유종 선택 → **🔄 오피넷 유가 조회**(전국/시도별)
5. **주행 거리·실비** — 자동 입력값 확인·수정, 주차료 입력, (근무지외) 식비·일비 포함 여부
6. **🧮 출장비 자동 계산** → **PDF / CSV 다운로드**, 정산 텍스트 복사

## 3. 여비 규정 (시간단위 반영)

### 3-1. 출장 구분별 지급

| 구분 | 지급 내용 |
|---|---|
| **근무지내 국내출장** | 출장시간 **4시간 미만 10,000원 / 4시간 이상 20,000원** (점심시간 포함 계산, 10시~14시=4시간)<br>운임·일비·식비·숙박비 별도 지급 없음. 단, 도서 연결 유료도로 등 **불가피한 통행료는 별도 지급 가능** |
| **근무지외 국내출장** | 운임(연료비+통행료+주차료) + 식비 + 일비 |

### 3-2. 식비 (출장시간 비례, 국내 1일 25,000원)

| 출장시간 | 지급 비율 |
|---|---|
| 4시간 미만 | 식비의 **1/3** |
| 4시간 이상 ~ 6시간 미만 | 식비의 **2/3** |
| 6시간 이상 | **전액** |

### 3-3. 일비

1일 **25,000원** 정액 (1급 이하 기준) × 출장일수

### 3-4. 자가용 운임

```
연료비 = 출장거리(km) ÷ 기준연비 × 기준유가     (원 단위 절사/반올림/올림 선택)
통행료 = 고속도로 통행영수증 실비
주차료 = 영수증 실비, 1일 상한 25,000원(일비)
청구 총액 = 운임(+식비+일비)  또는  근무지내 정액(+불가피 통행료)
```

### 3-5. 연비·전비 기준 (2021 한국에너지공단 통계 등)

| 구분 | 연비·전비 | 단위 | 오피넷 코드 |
|---|---|---|---|
| 휘발유 / 고급휘발유 | 11.97 | km/L | B027 / B034 |
| 경유 | 12.52 | km/L | D047 |
| LPG(부탄) | 8.83 | km/L | K015 |
| 하이브리드 | 10.61 | km/L | B027 |
| 플러그인 하이브리드 | 15.37 | km/L | B027 |
| 전기 | 2.84 | km/kWh | — (충전요금 입력) |
| 수소 | 94.9 | km/kg | — (충전요금 입력) |

## 4. 경로 후보 비교 (네이버 지도 방식)

`GET https://apis-navi.kakaomobility.com/v1/directions?origin=…&destination=…&waypoints=…&priority=RECOMMEND&alternatives=true&road_details=true&summary=false`

- 경로 탐색 기준: 추천 / 최단 시간 / 최단 거리 / 큰길 우선
- `alternatives=true` 로 **복수 후보**를 받아 거리·시간·통행료를 표로 비교
- 지도에는 선택 경로(빨간 실선)와 나머지 후보(회색 점선)를 함께 표시
- **통행료는 엔진마다 산출값이 다를 수 있으므로**(카카오 vs 네이버) 입력창에서 수정 가능하며,
  실제 청구는 **통행영수증 실비** 기준입니다.

### 실측 비교 (김천 혁신로 288-7 → 대전 경유 → 서울역)

| 출처 | 거리 | 소요시간 | 통행료 |
|---|---|---|---|
| 카카오내비(앱) | 257.1 km | 4시간 44분 | 15,200원 |
| 네이버 지도 | 259 km | 4시간 54분 | 13,200원 |

거리·시간은 근접하며, 통행료 차이는 경로 탐색 엔진별 요금 산정 방식 차이입니다(영수증 실비로 정산).

### 주소 → 좌표

- 1순위: 카카오 주소검색/키워드검색 (`dapi.kakao.com/v2/local/search/...`)
- 2순위: OSM Nominatim (주소 변형 자동 재시도 — 광역 접두어 제거, 번지 제거, 시·군 단위)

> ⚠️ 카카오맵 서비스가 꺼져 있으면(`OPEN_MAP_AND_LOCAL disabled`) 자동으로 OSM으로 대체됩니다.
> **Kakao Developers → 내 애플리케이션 → 카카오맵 → 사용 설정 ON** 하면 카카오 주소검색이 활성화됩니다.

## 6. 증빙 보고서 PDF

1. **출장 개요** — 출장자·소속·사번, 출장구분, 기간, **출장시간**, 목적, 경로

5. **첨부 증빙서류** — 통행영수증 · 주유 매출전표 · 주차영수증 체크리스트

CSV는 `utf-8-sig`(Excel 한글 깨짐 방지)로 저장됩니다.

## 9. 유의사항

- 계산 결과는 **참고용**이며, 최종 지급액은 소속 부서의 규정 해석·증빙 확인으로 확정됩니다.
- 자가용 **동승자**에게는 연료비·통행료·주차료를 지급하지 않습니다.
- 2인 이상 동행 출장 시 **1대 차량 이용이 원칙**입니다.
- 업무용 차량 이용 시 운임은 지급하지 않고 **주차비·통행료만** 지급합니다.
- 근무지내/근무지외 판단(거리 12km, 교통여건 등)은 소속장 판단 사항입니다.
- 카카오 길찾기는 경유지 최대 5개, 총 경로 1,500km 미만까지 지원합니다.

### 10-1. 유료 API 없이 동작
| 용도 | API | 비용 |
|---|---|---|
| 주소→좌표 | **OSM Nominatim** (기본, 키 불필요) | 무료 |
| 주소→좌표 (선택) | **VWorld** 지오코더 (일 40,000건) | 무료 ([인증키](https://www.vworld.kr)) |
| 주소→좌표 (선택) | **도로명주소 API** ([승인키](https://business.juso.go.kr)) | 무료 |
| 경로·거리·통행료 | 카카오내비 길찾기 (보유 키) | 무료 한도 내 |
| 실시간 유가 | 오피넷 | 무료 |

**카카오맵(Local/지오코딩) 서비스는 사용하지 않습니다.** 유료 활성화가 필요 없습니다.
`secrets.toml`에 `VWORLD_API_KEY`, `JUSO_API_KEY`를 추가하면 주소 정확도가 더 올라갑니다.

### 10-2. 엑셀 출력 (사내 양식 재현)
`국내출장_여비집행리스트_YYYYMMDD.xlsx`

- **시트1 `출장비 집행 리스트`**: 제목(병합) · 예산과목 · 표
  `사번|성명|부서|직급|기간시작|기간끝|사유(용무)|행선지|업무용차량|출장여비|일비|식비|교통비|출장시간|주행거리(km)|연료비|통행료|주차료`
  · 총합계(SUM 수식) · **여비 지급 개인별 계좌번호** 섹션(성명별 SUM 수식)
- **시트2 `산출근거`**: 경로·차종·연비·유가·거리·항목별 금액·출장시간·경로엔진
- 여러 건을 **➕ 정산 목록에 추가**로 누적하면 한 장의 집행 리스트로 출력됩니다.

### 10-3. 출장시간 입력
출장 시작 시각 + 출장시간(시·분)을 입력하면 **기간시작/기간끝이 자동 계산**되어
엑셀 `기간시작`·`기간끝` 열에 `YYYY.MM.DD HH:MM` 형식으로 들어갑니다.
경로 자동계산 시 소요시간이 출장시간에 반영됩니다.

## 11. VWorld API 키 발급 가이드 (무료)

### 11-1. 어떤 API를 신청하나?
**`Geocoder API` (버전 2.0)** 하나만 신청하면 됩니다 — **주소를 좌표로 변환**하는 API입니다.
(VWorld 카탈로그에서 9번째 항목, `버전 2.0` 버튼)

| API | 필요 여부 | 용도 |
|---|---|---|
| **Geocoder API 2.0** | ✅ **필수** | 주소 → 좌표(경도/위도). 본 앱이 호출하는 API |
| 검색 API 2.0 | 선택 | 장소명·키워드 검색. 정확도 향상에 도움 |
| StaticMap API | ❌ 불필요 | 배경지도 이미지 — 본 앱은 지도를 직접 렌더링 |
| 2D지도 / 3D / WMS·WFS / WMTS | ❌ 불필요 | 지도 표출용 |

### 11-2. 발급 절차
1. <https://www.vworld.kr> 회원가입 → 로그인
2. **오픈API → 인증키 발급/관리** 메뉴
3. **API 선택: `Geocoder API`** 체크
4. **인증키 종류**
   - **개발키**: 즉시 발급, 유효기간 6개월 → **사내 테스트용으로 이걸 선택**
   - 운영키: 기관·사업자 정보 및 심의 필요 → 실서비스 전환 시 신청
5. **서비스 URL(도메인) 등록** ← ⚠️ **필수**
6. 발급된 키를 `secrets.toml`에 입력

### 11-3. ⚠️ 도메인 등록이 핵심
VWorld는 **인증키 발급 시 등록한 도메인과 요청의 `domain` 파라미터가 일치해야** 동작합니다.
불일치하면 `INCORRECT_KEY`(인증키 정보가 올바르지 않습니다) 오류가 납니다.

```toml
VWORLD_API_KEY = "발급받은 키"
VWORLD_DOMAIN  = "발급 시 등록한 서비스 URL"   # 예: localhost:8501
```

| 실행 환경 | 서비스 URL 등록 예시 |
|---|---|
| 내 PC에서 테스트 | `http://localhost:8501` → `VWORLD_DOMAIN = "localhost:8501"` |
| 사내 서버 | `http://expense.회사도메인` → `VWORLD_DOMAIN = "expense.회사도메인"` |

### 11-4. 호출 사양 (코드에 구현됨)
```
GET https://api.vworld.kr/req/address
    ?service=address&request=getcoord&version=2.0&crs=EPSG:4326
    &type=road|parcel&address=주소&format=json&errorformat=json
    &key=인증키&domain=등록도메인
→ response.result.point.x(경도), .y(위도)
```
- 일일 한도 **40,000건** (무료) · 결과를 DB 등에 저장하는 것은 금지(실시간 사용만)
- `type=road`(도로명주소) 실패 시 `type=parcel`(지번주소)로 자동 재시도

### 11-5. 키를 넣지 않아도 되나?
네. `VWORLD_API_KEY`가 비어 있으면 자동으로 **OSM(Nominatim)** 으로 대체되어 앱이 정상 동작합니다.
다만 OSM은 좌표가 미세하게 흔들려 거리 값이 실행마다 조금씩 달라질 수 있으므로,
**정확한 고정 좌표가 필요하면 VWorld 키 등록을 권장**합니다.

## 12. 배포하고 VWorld 도메인 등록하기 (전체 순서)

### 왜 필요한가
VWorld는 **인증키 발급 시 등록한 도메인**과 요청의 `domain` 값이 **일치해야** 응답합니다.
불일치하면 `INCORRECT_KEY`(인증키 정보가 올바르지 않습니다) 오류가 납니다.
따라서 **먼저 접속 가능한 사이트 주소를 만든 뒤**, 그 주소를 등록하고 키를 받아야 합니다.

### 1단계 — GitHub 저장소 만들기 (무료)
1. <https://github.com> 로그인 → 우측 상단 **+ → New repository**
2. **Repository name**: `trip-expense` (원하는 이름)
3. **Public** 선택 → **Create repository**
4. **Add file → Upload files** 로 아래를 업로드
   - `app.py`, `requirements.txt`
   - **`assets/` 폴더 전체** (한글 폰트 2개 + 지도 GeoJSON 2개, 약 9MB)
5. **Commit changes**

> ⚠️ **`.streamlit/secrets.toml` 은 GitHub에 올리지 마세요.** 인증키가 공개됩니다.
> 대신 2단계의 Cloud Secrets 화면에 입력합니다. (`.gitignore` 에 추가 권장)

### 2단계 — Streamlit Community Cloud 배포 (무료)
1. <https://share.streamlit.io> → **GitHub 계정으로 로그인**(권한 승인)
2. 우측 상단 **Create app** → *"Do you already have an app?"* → **Yup, I have an app**
3. **Repository**: `<계정>/trip-expense` · **Branch**: `main` · **Main file path**: `app.py`
4. **App URL** 에 원하는 서브도메인 입력 → 예: `trip-expense-kr`
   → 배포 주소 **`https://trip-expense-kr.streamlit.app`**
5. **Advanced settings → Secrets** 에 `secrets.toml` 내용을 붙여넣기 (키는 나중에 갱신 가능)
6. **Deploy** → 2~3분 뒤 접속 가능

> 배포가 끝나면 이 주소가 **VWorld에 등록할 도메인**입니다.
> (커스텀 서브도메인을 비우면 `계정-저장소-파일-해시.streamlit.app` 형태로 자동 생성됩니다.
>  이후 **App settings** 에서 언제든 변경 가능하지만, 변경 시 VWorld 도메인도 함께 수정해야 합니다.)

### 3단계 — VWorld에 도메인 등록 & 키 발급/갱신
1. <https://www.vworld.kr> 로그인 → **오픈API → 인증키 발급/관리**
2. **신청 API: `Geocoder API`** (버전 2.0) 체크
3. **인증키 종류: `개발키`** — 즉시 발급, 유효기간 6개월
   (최대 3회 연장해 총 12개월 사용 가능 · ID당 최대 10개 발급 · 실서비스 전환 시 운영키 신청)
4. **서비스 URL(도메인)** 에 2단계에서 확인한 주소 입력
   - 예: `https://trip-expense-kr.streamlit.app`
   - 로컬 테스트도 병행하려면 `localhost:8501` 도 함께 등록(화면에서 추가 가능 여부 확인)
5. 발급(또는 기존 키의 도메인 **수정**) 후 **키 복사**

### 4단계 — Cloud Secrets 갱신
`share.streamlit.io` → 해당 앱 → **Settings → Secrets** 에 아래를 넣고 저장(앱 자동 재시작)

```toml
OPINET_CERTKEY     = "오피넷 키"
KAKAO_REST_API_KEY = "카카오 키"
VWORLD_API_KEY     = "발급받은 VWorld 키"
VWORLD_DOMAIN      = "trip-expense-kr.streamlit.app"
JUSO_API_KEY       = ""
```

### 5단계 — 확인
앱에서 주소 입력 → **📍 경로·거리 자동 계산** → **경로 계산 로그**에
`📍 서울특별시 … (VWorld)` 가 보이면 성공입니다.

| 로그 메시지 | 원인 / 조치 |
|---|---|
| `(VWorld)` | ✅ 정상 |
| `⚠️ VWorld 인증키 도메인 불일치(INCORRECT_KEY) … → OSM으로 대체` | `VWORLD_DOMAIN` 값을 등록한 문자열과 **똑같이** 수정 |
| `⚠️ VWorld 호출 실패 …` | 네트워크/방화벽 또는 서버 일시 오류 — OSM으로 자동 대체되어 앱은 계속 동작 |
| `(OSM(Nominatim))` | VWorld 키 미설정 또는 실패 → 폴백 동작 중 |

### 도메인 문자열 형식 주의
- 등록 화면이 `http://` 포함을 요구하면 **그대로** 입력하고, `VWORLD_DOMAIN` 에도 **등록한 문자열과 동일하게** 넣습니다.
- 사내 서버로 운영한다면 그 주소(예: `expense.회사도메인`)를 등록하고 `VWORLD_DOMAIN` 에 넣으면 됩니다.
- 로컬 실행(`streamlit run app.py`) 시에는 `VWORLD_DOMAIN = "localhost:8501"`.

### 부록 — 로컬(내 PC)에서만 쓸 때
배포 없이 쓰려면 로컬 주소를 등록해도 됩니다.
```bash
streamlit run app.py          # → http://localhost:8501
# secrets.toml
VWORLD_DOMAIN = "localhost:8501"
```
단, 로컬 주소는 **다른 PC에서 접속할 수 없으므로** 팀 공용으로 쓰려면 1~2단계 배포가 필요합니다.
